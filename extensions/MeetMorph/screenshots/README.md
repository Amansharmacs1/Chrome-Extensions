# MeetMorph Screenshots Guide

This directory holds screenshots of MeetMorph for the GitHub repository and documentation.

## Required Screenshots Checklist

Capture genuine screenshots using the steps below and save them with the following filenames:

1. **`popup.png`**
   - **View:** MeetMorph extension popup opened in Chrome.
   - **How to capture:** Click the MeetMorph puzzle/pinned extension icon in Google Chrome toolbar while on Google Meet or the local test room. Take a window screenshot (`⌘+Shift+4` then `Spacebar` on macOS).
   - **Suggested dimensions:** ~380 × 600 px.

2. **`meetmorph-in-meeting.png`**
   - **View:** Active Google Meet session showing the in-page MeetMorph floating HUD in the bottom-right corner.
   - **How to capture:** Join a Google Meet call (`https://meet.google.com/`), turn on your camera, and capture the screen showing the floating HUD in `Live` mode.

3. **`meetmorph-vanished.png`**
   - **View:** Active Google Meet session while in `VANISHED` mode.
   - **How to capture:** In the meeting, click **Vanish** (or press `⌘+Shift+V`). Capture the screen showing the outgoing video displaying the empty room with the purple `Vanished` badge.

4. **`test-room.png`**
   - **View:** Local WebRTC loopback test room (`test-room.html`).
   - **How to capture:** Open `test-room.html` in Chrome, click "Start Meeting Camera" and "Connect Participant", and capture the dual-video telemetry screen.
