# MeetMorph — Privacy Policy & Data Handling

**Last Updated:** October 2026

This document details the exact data handling, storage practices, and privacy boundaries of the **MeetMorph** Chrome Extension, verified directly by source code audit.

---

## 1. Summary of Data Practices

- **Zero Telemetry:** MeetMorph does not collect, log, or transmit any analytics, crash reports, user identifiers, or usage telemetry.
- **Zero External Network Requests:** The extension makes **no** HTTP/HTTPS requests to any external server, third-party API, or cloud storage.
- **Local On-Device Processing:** All webcam frame rendering, canvas stream generation, and audio transient analysis are performed 100% locally on your machine.
- **No Video or Audio Recording:** MeetMorph never records, captures video files, or stores audio buffers.
- **Strictly Local Storage:** Only the user's captured background snapshot (single JPEG base64 string) and user UI preferences are stored, using Chrome's sandboxed `chrome.storage.local`.

---

## 2. Detailed Data Inventory

### A. Video Data
- **What is accessed:** The live video track returned by your webcam when Google Meet requests camera access.
- **How it is used:** The video track is routed into an offscreen HTML5 `<canvas>` element in the page's memory. In `VISIBLE` mode, live frames are rendered to the canvas at 30 FPS. In `VANISHED` mode, the static background image is rendered to the canvas.
- **Storage:** Video frames are **never** recorded or saved to disk. When the user explicitly clicks "Capture Empty Background", a single static image snapshot is encoded into a local base64 JPEG data URL and stored in `chrome.storage.local`.
- **Transmission:** The video track generated by `canvas.captureStream(30)` is passed directly into Google Meet's native WebRTC peer connection. The extension does not intercept or transmit this video to any third party.

### B. Audio Data
- **What is accessed:** The native microphone track returned by `getUserMedia` when Google Meet requests microphone access.
- **How it is used:**
  1. The microphone track is passed directly and unmodified to Google Meet's WebRTC peer connection. MeetMorph **does not modify, filter, mute, or replace** the outgoing microphone stream.
  2. If the optional "Finger Snap Trigger" feature is enabled, a cloned audio node is connected to a local Web Audio API `AnalyserNode` and Biquad filter to detect transient energy spikes (>2.2 kHz).
- **Storage:** Audio data is **never** recorded, buffered to disk, or stored. Audio samples in the transient detector are discarded immediately after computing Root Mean Square (RMS) energy.
- **Transmission:** No audio is ever transmitted to any destination other than the meeting participants via Google Meet's native WebRTC connection.

### C. Extension Settings & Local Storage (`chrome.storage.local`)
The extension stores only the following keys locally within your browser profile:
- `savedBackgroundDataUrl`: Base64 JPEG string of the empty room snapshot captured by the user.
- `backgroundMetadata`: Resolution (`width`, `height`), timestamp, and average luma value of the captured snapshot.
- `snapEnabled`: Boolean indicating if finger snap detection is enabled (default `false`).
- `snapSensitivity`: Integer (1 to 10) indicating snap detection threshold (default `6`).
- `hudMinimized`: Boolean indicating whether the floating HUD is collapsed.

---

## 3. Third-Party Services & Dependencies

- **Analytics / Tracking:** None.
- **Advertising:** None.
- **Third-Party Libraries:** MeetMorph uses zero runtime external dependencies. All logic is implemented in pure vanilla JavaScript and native browser Web APIs (`MediaDevices`, `HTMLCanvasElement`, `Web Audio API`, `RTCPeerConnection`).

---

## 4. User Control & Data Deletion

- **Deleting Stored Background:** To clear your captured background, click **Recapture** to overwrite it, or uninstall the extension from `chrome://extensions`, which immediately purges all keys in `chrome.storage.local`.
- **Revoking Permissions:** Camera and microphone permissions can be revoked at any time by clicking the lock/site settings icon in Chrome's address bar on `meet.google.com`.
